المشتبه به الخفي — النسخة البوليسية

التشغيل: فك الضغط ثم افتح index.html في متصفح حديث. احتفظ بمجلد assets بجانبه.
الصوت: اضغط زر تشغيل أصوات التحقيق لتفعيل الخلفية الخافتة والمؤثرات؛ اضغطه مجددًا للكتم. يتوقف الصوت عند إخفاء الصفحة. لا يحتاج ملفات صوت خارجية.
للنشر: ارفع index.html ومجلد assets إلى الاستضافة التي تختارها.
ملف index.html المرفق خارج ZIP يحتوي الصور داخله، ويمكن فتحه وحده.

المحتوى: ملاحظات المحقق، ثلاثة أدلة تفاعلية، إفادة مضللة، توثيق مساعدة الأدوات ومساهمة صاحبة المشروع، المصادر، كشف الهوية، ومحضر النهاية.
الصور التوضيحية للأدلة مقتطفة من الصورة المرجعية المرفقة. خلفية المكتب مولدة بالذكاء الاصطناعي.
خط Cairo يحتاج اتصالًا بالإنترنت؛ عند غياب الاتصال يستخدم الموقع الخطوط المحلية تلقائيًا. روابط المصادر تحتاج اتصالًا.

التحقق: اجتازت JavaScript فحص الصياغة، واجتاز تسلسل التفاعلات اختبارًا برمجيًا لمحاكاة عناصر الصفحة: الآثار الثلاثة، الإجابات الخاطئة والصحيحة، تقدّم الأدلة، شروط الانتقال، الإفادة المضللة وإعادة القرار، كشف الهوية، نسخ الملخص ومساره البديل، وإعادة التحقيق.
هذه اختبارات منطقية وليست تشغيلًا داخل متصفح فعلي. تعذرت المعاينة داخل المتصفح بسبب قيود الوصول إلى الملفات والخادم المحلي. لم يُختبر على هاتف فعلي.
تُحفظ نتائج الأدلة فقط في الجلسة الحالية. زر إعادة التحقيق يمسحها.
